# Fengji Li — Personal Academic Website

This repository hosts the personal academic website of me.

🌐 **Website:** [https://lifengji.com](https://lifengji.com)

I am a postdoctoral researcher in biomedical engineering at Beihang University.  
My research interests include physiological speech interfaces, flexible ultrasound,
multimodal speech decoding, speech reconstruction, and biomedical signal processing.

## Website

The website includes:

- **Home** — Profile and research interests
- **News** — Recent academic activities and updates
- **Research** — Research topics and ongoing work
- **Publications** — Selected publications
- **Projects** — Research projects and collaborations
- **CV** — Education, research experience, and academic activities

## Built With

This website is built with [Jekyll](https://jekyllrb.com/) and the
[Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) theme.

The repository was originally initialized using
[Chirpy Starter](https://github.com/cotes2020/chirpy-starter)
and has since been customized for use as a personal academic website.
